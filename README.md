# Udemy Clone (HTML & CSS)

This is a simple **Udemy homepage clone** created using **HTML and CSS**.
The purpose of this project is to practice **Flexbox layout** and basic webpage design.

In this project, I recreated a Udemy-style page that includes a navigation bar, course sections, topic suggestions, and a footer.

## Sections Included

* Navbar with logo and search bar
* Course categories
* Recommended courses
* Topics recommended for you
* Most popular courses
* Footer section

## Technologies Used

* HTML
* CSS
* Flexbox

## Purpose of the Project

This project helped me understand how to structure a webpage and use **Flexbox to arrange elements on a page**.

This is a beginner practice project created as part of my **web development learning journey**.
